# Unity 3D Physics Platformer Prototype

A minimalist 3D physics-based platformer built from scratch in **Unity 6** and **C#**.

## Gameplay & Features
- **Physics-Based Player Controller:** Rigidbody movement, jumping, and custom Physics Materials.
- **Multi-Level Progression:** Three distinct scenes (`Level0`, `Level1`, and `Level2`) where players knock the target capsule off the platform to advance.
- **Fail-State Reset Logic:** Automatic scene reload when falling off the platform.
- **Audio Feedback:** Collision-triggered sound effects via Unity's Audio Source component.

## Built With
- **Engine:** Unity 6
- **Language:** C#
- **Version Control:** Git & GitHub
